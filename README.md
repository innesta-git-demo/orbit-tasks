# Orbit Tasks

A small task manager for everyday work: what is still open, what is done, and nothing else
in the way.

## Getting started

```sh
npm install
npm run dev
```

Vite prints the address to open, usually http://localhost:5173.

## Scripts

| Script | What it does |
|---|---|
| `npm run dev` | Starts the development server |
| `npm test` | Runs the unit tests with Vitest |
| `npm run typecheck` | Checks the types |
| `npm run build` | Checks the types and builds the app into `dist/` |
